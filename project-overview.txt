# TechTales Project Overview

## Project Description
TechTales is an interactive educational platform designed to teach technology concepts through engaging games and structured courses. The platform targets learners interested in AI, programming, and computer science fundamentals, making complex topics accessible and fun through gamification.

## What the Project is About
TechTales aims to revolutionize technology education by:
- Providing hands-on learning experiences through interactive games
- Offering structured courses on AI, machine learning, and programming concepts
- Creating a safe, engaging environment for users to experiment and learn
- Using modern web technologies to deliver rich, responsive experiences
- Incorporating AI-powered features for personalized learning paths

## Target Audience
- Students learning computer science and AI concepts
- Educators looking for interactive teaching tools
- Technology enthusiasts wanting to explore AI and programming
- Anyone interested in understanding how technology works through play

## Core Features
1. **Interactive Games**: Multiple educational games teaching specific tech concepts
2. **Course Management**: Structured learning paths with lessons and topics
3. **User Authentication**: Secure login/signup system with JWT tokens
4. **Dashboard**: Personalized user dashboard showing progress and achievements
5. **Chatbot Integration**: AI-powered chatbot for assistance and guidance
6. **Responsive Design**: Works seamlessly across desktop and mobile devices

## Technology Stack

### Frontend
- **React 19.2.4**: Modern JavaScript library for building user interfaces
- **React Router DOM 7.13.0**: Declarative routing for React applications
- **CSS**: Custom styling with responsive design principles
- **Lottie React 2.4.1**: For smooth animations and micro-interactions

### Backend
- **Node.js with Express 5.2.1**: Server-side JavaScript runtime and web framework
- **PostgreSQL 8.20.0**: Robust relational database for data persistence
- **JWT (JSON Web Tokens) 9.0.3**: Secure authentication and authorization
- **bcrypt 6.0.0**: Password hashing for security
- **CORS 2.8.6**: Cross-origin resource sharing middleware
- **Helmet 8.1.0**: Security middleware for HTTP headers
- **Express Rate Limit 8.3.2**: API rate limiting for security

### AI and External Services
- **Google Generative AI 0.24.1**: Integration with Google's AI models for chatbot and intelligent features
- **dotenv 17.3.1**: Environment variable management

### Development and Testing
- **React Scripts 5.0.1**: Build scripts and development server for React
- **Testing Library (Jest, React Testing Library)**: Comprehensive testing suite
- **ESLint**: Code linting and style enforcement
- **Web Vitals 2.1.4**: Performance monitoring

## Project Structure

### Root Directory
- `package.json`: Project dependencies and scripts
- `README.md`: Project documentation
- `Server.js`: Main backend server file
- `generate-icons.js`: Icon generation utility

### Public Directory
- Static assets served by the React app
- `index.html`: Main HTML template
- `manifest.json`: Web app manifest for PWA features
- `robots.txt`: Search engine crawling instructions
- `service-worker.js`: Service worker for offline functionality

### Src Directory
- **components/**: Reusable React components
  - `Chatbot.js`: AI-powered chat interface
  - `ProtectedRoute.js`: Route protection for authenticated users

- **data/**: Static data files
  - `courses.js`: Course definitions and content

- **games/**: Educational game components
  - `TrainModelGame.js`: AI model training simulation
  - `PatternDetectiveGame.js`: Pattern recognition game
  - `RobotCommanderGame.js`: Programming logic game
  - `WordChallengeGame.js`: AI keyword formation game
  - Other game files for various learning activities

- **pages/**: Main application pages
  - `Auth.css/js`: Authentication pages (Login, Signup, Forgot Password)
  - `Courses.css/js`: Course browsing and management
  - `Dashboard.css/js`: User progress dashboard
  - `Home.css/js`: Landing page
  - `Learn.js`: Learning interface
  - `Lesson.css/js`: Individual lesson pages
  - `Play.css/js`: Game selection and play area
  - `Topics.css/js`: Topic exploration

- **Root Files**:
  - `App.js`: Main application component
  - `App.css`: Global styles
  - `index.js`: Application entry point
  - `index.css`: Base styles
  - `reportWebVitals.js`: Performance reporting
  - `serviceWorkerRegistration.js`: PWA service worker registration
  - `setupTests.js`: Test configuration

### Build Directory
- Production build output
- Optimized static files for deployment

## Games and Educational Content

### Available Games
1. **Train the Model**: Label data to teach an AI classifier, demonstrating training quality impact
2. **AI Pattern Detective**: Spot hidden patterns in sequences, mirroring AI learning processes
3. **Robot Commander**: Write command sequences for robot execution, teaching programming logic
4. **AI Word Challenge**: Drag-and-drop word formation with AI-related keywords

### Course Structure
- Modular lessons covering AI, machine learning, and programming concepts
- Progressive difficulty levels
- Interactive exercises and assessments

## Authentication and Security
- JWT-based authentication system
- Password hashing with bcrypt
- Protected routes for authenticated content
- Rate limiting to prevent abuse
- CORS configuration for secure API access
- Helmet for security headers

## Database Schema (PostgreSQL)
- User accounts and profiles
- Course progress tracking
- Game scores and achievements
- Session management

## Development Workflow
1. **Installation**: `npm install` for dependencies
2. **Development**: `npm start` runs development server
3. **Building**: `npm run build` creates production build
4. **Testing**: `npm test` runs test suite
5. **Deployment**: Built files can be served by any static hosting or integrated with backend

## Deployment Considerations
- Frontend can be deployed to services like Vercel, Netlify, or AWS S3
- Backend requires Node.js hosting (Heroku, DigitalOcean, AWS EC2)
- Database needs PostgreSQL hosting (AWS RDS, Google Cloud SQL, etc.)
- Environment variables for API keys and database credentials
- HTTPS required for production (security and PWA features)
